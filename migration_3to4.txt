* Server

  1. ntex::server::build() accepted service factory closure

     AsyncFn() -> ServiceFactory<.., InitCfg = SharedCfg>

   in v4 ServerBuilder and all other builders based on ntex-server accept

     AsyncFn() -> Service<>


* HttpService (ntex::http)

1. http::HttpService::openssl(), http::HttpService::rustls()
   are replcaed with http::openssl / http::rustls

   ```rust
   http::HttpService::new(....)
       .openssl(acceptor);

   http::openssl(acceptor, http::HttpService::new(..))
   ```

* http client

1. ClientBuilder and Connector merged to one

2. All connector service factories are replaced with Service

3. .build() methods of builders are not async anymore

4. client configuration is part of ntex_service::cfg now.

   ```rust
   use ntex::SharedCfg;
   use ntex::client::{Client, ClientConfig};

   fn create_client() -> Client {
      let cfg = SharedCfg::new("client").add(
          ClientConfig::new()
             .set_limit(8)
             .set_response_payload_limit(265 * 1024)
      );

      Client::builder()
          .connector(ntex::connect::Service::new())
          .build(cfg)

   }
   ```

* websocket client

 Configuration is moved to `WsClientConfig` type. WsClient does not require
 builder anymore.
